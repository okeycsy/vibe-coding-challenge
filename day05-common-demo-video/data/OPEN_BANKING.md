# 오픈뱅킹 회비 산정 기준 (OPEN_BANKING)

- 업무명: 오픈뱅킹
- 산정 유형: 균등분담회비 30% + 실적분담회비 70% (회비 총액은 전체 인정 건수에 구간별 차등 단가 적용)
- 표시 단위: 원

## 1. 비즈니스 규칙 요약

1. 기본 원칙
- 균등분담회비 총액은 전체 회비의 정확히 30%로 한다.
- 실적분담회비는 나머지 70%를 기준으로 산출한다.
- 기관별 회비의 소수점은 첫째 자리에서 반올림한다.

2. 균등분담회비 보정
- 반올림 후 균등분담회비 합계가 30%를 초과하면, 실적분담회비가 큰 기관부터 균등분담회비를 1원씩 차감한다.
- 30%에 미달하면, 실적분담회비가 작은 기관부터 균등분담회비를 1원씩 증액한다.
- 최종 균등분담회비 총액은 정확히 30%를 유지한다.

3. 회비 총액과 인정 실적
- 이용기관 API 호출 중 출금이체·입금이체 성공 건을 실적으로 인정한다 (조회성 API는 산정 제외).
- 전체 회비는 산출 기간 전체 인정 건수에 구간별 차등 단가(누진 감액)를 적용해 정한다: 100만 건까지 건당 20원, 100만 건 초과 ~ 300만 건 15원, 300만 건 초과분 10원.
- 균등분담회비는 참가기관 수로 똑같이 나누고, 실적분담회비는 기관별 인정 건수 비율로 나눈다.
- 장애·중복 전송 건은 증빙 확인 후 실적에서 차감한다.

## 2. AI 예외 차감 지침

- 시스템 장애로 이용기관이 같은 거래를 다시 보낸 경우, 재전송된 건수만큼 차감한다.
- 같은 거래고유번호로 2회 이상 들어온 중복 전송 건은 1건만 남기고 차감한다.
- 이용기관 쪽 단순 오류(잘못된 계좌번호 등)로 실패한 건은 애초에 성공 건이 아니므로 차감 대상이 아니다.
- 기관명과 건수가 문장에 없으면 차감하지 않고 담당자에게 확인을 요청한다.

## 3. 정산 수식

변수: `#finalCount` 기관 인정 건수, `#totalCount` 전체 인정 건수 합계, `#institutionCount` 참가기관 수.
회비 총액 = 전체 인정 건수의 구간별 차등 단가 합계. 균등분담분은 총액의 30%를 기관 수로 나누고, 실적분담분은 총액의 70%를 인정 건수 비율로 나눈다 (단가는 각 줄의 20·15·10 만 바꾸면 된다).

```formula:equal
#institutionCount == 0 ? 0 : 0.3 * ((#totalCount < 1000000 ? #totalCount : 1000000) * 20 + (#totalCount > 1000000 ? (#totalCount < 3000000 ? #totalCount : 3000000) - 1000000 : 0) * 15 + (#totalCount > 3000000 ? #totalCount - 3000000 : 0) * 10) / #institutionCount
```

```formula:perf
#totalCount == 0 ? 0 : 0.7 * ((#totalCount < 1000000 ? #totalCount : 1000000) * 20 + (#totalCount > 1000000 ? (#totalCount < 3000000 ? #totalCount : 3000000) - 1000000 : 0) * 15 + (#totalCount > 3000000 ? #totalCount - 3000000 : 0) * 10) * #finalCount / #totalCount
```

## 4. 최종 정산 특이사항

1. 울릉도 회비 보정
- 울릉도의 균등분담회비 + 실적분담회비 합계는 반드시 일의 자리가 0원이어야 한다.
- 일의 자리가 0원이 아니면 10원 단위로 올림한다. 예: 123원 → 130원
- 올림으로 증가한 금액은 울릉도 실적분담회비에 가산한다.
- 해당 증가액만큼 울릉도를 제외한 기관 중 실적분담회비가 큰 기관부터 1원씩 차감한다.
- 전체 회비 총액은 변하지 않아야 한다.

2. 최종 검증
- 균등분담회비 합계 = 전체 회비의 30%
- 울릉도 최종 회비의 일의 자리 = 0원
- 울릉도 증액분 = 다른 기관들의 감액분 합계
- 모든 최종 회비는 0원 이상의 정수
- 실적분담회비가 같은 경우 기관코드 오름차순 적용

```postprocess
roundHalf(equal)                                   # 기관별 균등분담회비 소수점 첫째 자리에서 반올림
roundHalf(perf)                                    # 기관별 실적분담회비 반올림
fixSum(equal, 30%, over=perfDesc, under=perfAsc)   # 균등분담회비 합계를 정확히 30%로 (초과: 실적분담 큰 기관부터 1원씩 차감, 미달: 작은 기관부터 1원씩 증액)
fixSum(perf, 70%, over=perfDesc, under=perfAsc)    # 실적분담회비 합계는 나머지 70%
roundUp(fee, 10, "울릉도", addTo=perf)             # 울릉도 회비 일의 자리 0원: 10원 단위로 올림, 증가분은 실적분담회비에 가산
spreadDiff(perf, others, perfDesc)                 # 증가분만큼 울릉도를 제외한 실적분담 큰 기관부터 1원씩 차감
assert sum(equal) == 30%
assert fee("울릉도") % 10 == 0
assert sum(fee) == before
assert all(fee >= 0)
```
