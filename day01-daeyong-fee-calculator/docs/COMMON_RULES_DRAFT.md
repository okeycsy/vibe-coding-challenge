# 회비 산출 공통 규칙 (초안)

> 상태: **초안**. 대용 작업에서 작성했으며, 공용 규칙으로 쓰려면 "공통_회비 산출" 프로젝트에서 확정한다. 확정 전까지는 대용 작업에만 적용한다.
> 근거: "회비 산출 프로그램 개발 요구사항 (통합본)"(2026-10-22), 대용 v4 구현(`docs/DESIGN.md`).

이 문서는 어떤 화면·기술로 만들든 회비 산출 프로그램이 **같은 입력에 같은 금액**을 내도록 지켜야 할 규칙이다. 규칙 번호(R-x.x)로 참조한다.

- **필수**: 요구사항에 명시된 규칙. 모든 구현이 그대로 따른다.
- **설정**: 업무마다 담당자가 고르는 옵션. 구현은 모든 선택지를 지원한다.
- **확인 필요**: 요구사항에 없는 규칙. 임의로 확정하지 않고, 기본값으로 계산하되 화면에 "확인 필요"로 표시한다 (9장).

---

## 1. 기본 원칙

- R-1.1 (필수) 모든 최종 금액은 원화 정수(원)다. 계산은 정수 또는 고정 소수(BigInt, Decimal 등)로 하고 부동소수점을 쓰지 않는다.
- R-1.2 (필수) 하나의 공식을 모든 업무에 강제하지 않는다. 산출 방식은 업무별 설정(2장)으로 결정한다.
- R-1.3 (필수) 계산 로직은 화면과 분리한다. 화면은 계산 결과와 산출 근거만 보여 주고 직접 계산하지 않는다.
- R-1.4 (필수) 같은 입력·같은 설정이면 언제나 같은 결과가 나온다. 계산 단계(8장)는 정해진 순서로 한 번씩만 적용하고 조정을 중복 적용하지 않는다.
- R-1.5 (필수) 어떤 조정 이후에도 기관별 최종 회비 합계 = 해당 분기 청구 대상 총액이다.
- R-1.6 (필수) 이미 청구한 1분기 회비는 잉여금 확정 이후 바꾸지 않는다.
- R-1.7 (필수) 저장소가 Public이므로 실제 기관 명단·실적·금액은 커밋하지 않는다. 예시 데이터(A기관, B기관 …)만 쓴다.

## 2. 업무별 설정

- R-2.1 (필수) 업무마다 아래 설정을 따로 저장하고, 다음 분기·다음 연도에 다시 불러 쓸 수 있다.

| 설정 | 선택지 | 장 |
|---|---|---|
| 균등·실적 비율 | 직접 입력 (예: 25% / 75%), 합 100% 확인 | 3 |
| 분기 배분 방식 | A 상·하반기 동일 / B 잔여 3분기 균등 | 4 |
| 균등회비 방식 | A 총액 정확성 우선 / B 기관별 동일 금액 우선 | 5 |
| 실적 인정 항목 | 체크박스 다중 선택 + 사용자 정의 항목 추가 | 6 |
| 우체국 특수 처리 | 적용 여부, 올림/내림, 반대 조정 기관 | 7 |
| 엑셀 열 매핑 | 머리글 → 기관명/항목/합계/기간/무시, 저장 재사용 | 10 |
| 실적 기준기간 | 시작일~종료일 (분기에 고정하지 않음) | 10 |
| 참가기관 | 분담 대상 포함/제외 | 11 |

## 3. 회비 구성

- R-3.1 (필수) 분기 회비 총액 T = 균등회비 총액 + 실적회비 총액.
- R-3.2 (필수) 균등 비율 + 실적 비율 = 100%가 아니면 경고한다.
- R-3.3 (필수) 실적회비 총액은 T − 균등회비 총액으로 구한다 (두 비율을 각각 곱해 생기는 원 단위 불일치를 막기 위함).

## 4. 연간 회비와 분기 배분

기호: A 당초 연간 회비, B 전기이월잉여금, C 1분기 기청구 회비, D 최종 연간 회비, E 2~4분기 청구 대상.

- R-4.1 (필수) 1분기 청구 대상 = A ÷ 4 (잉여금 미확정 상태).
- R-4.2 (필수) D = A − B, E = D − C. B > A면 오류로 막는다.
- R-4.3 (설정) 분기 배분 방식
  - 방식 A: 2분기 = D/2 − C, 3분기 = 4분기 = D/4
  - 방식 B: 2분기 = 3분기 = 4분기 = (D − C)/3
- R-4.4 (필수) 1~4분기 합계 = D. 나누어떨어지지 않으면 차액을 표시하고 담당자가 보정하게 한다.
- 예시 (A 100,000,000 / B 12,000,000 / C 25,000,000): 방식 A 25,000,000 · 19,000,000 · 22,000,000 · 22,000,000, 방식 B 25,000,000 · 21,000,000 × 3. 구현은 이 예시를 테스트로 갖는다.

## 5. 균등회비

- R-5.1 (설정) 방식 A, 총액 정확성 우선: 균등회비 총액 = T × 균등 비율을 분담 대상 기관 수로 나누고, 나머지 원은 담당자가 고른 기관에 ±1원씩 배정한다. **기관별 균등회비 합계 = 균등회비 총액**.
- R-5.2 (설정) 방식 B, 동일 금액 우선: 모든 기관의 균등회비가 정확히 같다 (자동 산출 또는 담당자 직접 지정). 실제 균등 비율을 계산해 설정 비율과의 차이를 표시하고, 차이만큼 실적회비 총액이 달라져 T는 유지한다.
- R-5.3 (필수) 원 미만 처리(반올림·올림·내림)를 선택할 수 있다.

## 6. 실적회비

- R-6.1 (필수) 기관별 실적회비 = 실적회비 총액 × 기관 인정 실적 ÷ 전체 인정 실적.
- R-6.2 (설정) 인정 실적 = 선택한 실적 항목 건수의 합 (예: 압류만 / 압류+추심 / 압류+추심+해제 / 사용자 정의 항목).
- R-6.3 (필수) 선택을 바꾸면 인정 실적과 실적회비를 즉시 다시 계산한다.
- R-6.4 (필수) 전체 인정 실적이 0이면 배분하지 않고 오류로 알린다.
- R-6.5 (필수) 원 미만은 버린 뒤 남은 원을 1원씩 배정해 합계 = 실적회비 총액 (배정 순서는 9장 확인 필요).

## 7. 우체국 특수 처리

- R-7.1 (필수) 우체국 최종 청구액의 1원 자리는 0 (10원 단위).
- R-7.2 (설정) 올림/내림은 담당자가 고른다. 예: 1,234,567원 → 올림 1,234,570원(+3) / 내림 1,234,560원(−7).
- R-7.3 (필수) 보정은 우체국의 균등회비가 아니라 **실적회비**에서 한다.
- R-7.4 (필수) 같은 차액을 담당자가 지정한 다른 기관의 실적회비에서 반대로 조정해 전체 합계를 유지한다. 반대 기관 실적회비가 음수가 되면 오류.
- R-7.5 (필수) 조정 전후 금액을 비교해 보여 준다.

## 8. 계산 순서

1. 업무·산출 대상 설정 → 2. A·B 반영 → 3. 분기 총액 T → 4. 실적 엑셀 업로드·검증 → 5. 인정 항목 선택 → 6. 균등·실적 총액 → 7. 기관별 균등회비 → 8. 기관별 실적회비 → 9. 원 단위 잔액 처리 → 10. 우체국 처리 → 11. 합계 검증 → 12. 산출 근거 → 13. 결과 엑셀

- R-8.1 (필수) 각 단계는 앞 단계 결과만 입력으로 받고, 앞 단계의 조정을 다시 적용하지 않는다.

## 9. 담당자 확인이 필요한 항목

요구사항에 없어 **임의로 확정하지 않는** 항목이다. 구현은 아래 기본값으로 계산하되 "확인 필요"로 표시하고, 담당자가 업무별로 값을 바꾸거나 "이 값으로 확인"해 확정한다. 확정 여부는 결과 엑셀에도 남긴다. 기본값은 대용 v4 기준이며, 공통 확정 시 바뀔 수 있다.

| # | 항목 | 기본값 (미확정) |
|---|---|---|
| D-1 | 1분기 기청구 회비 | A ÷ 4 자동 (실제 청구액 직접 입력 가능) |
| D-2 | 분기 금액이 나누어떨어지지 않을 때 | 내림 |
| D-3 | 분기 배분 차액을 반영할 분기 | 차액이 생기면 그때 선택 (선택 전에는 검증 불일치) |
| D-4 | 균등회비 총액(방식 A)의 원 미만 처리 | 반올림 |
| D-5 | 기관별 균등회비 기본금액(방식 A)의 원 미만 처리 | 내림 |
| D-6 | 균등회비 ±1원 대상 기관(방식 A) | 참가기관 목록 순서대로 |
| D-7 | 방식 B 기관별 금액의 단위와 처리 | 1원 단위 내림 (직접 지정 가능) |
| D-8 | 실적회비 원 단위 잔액 배정 | 버린 소수점이 큰 기관부터 1원씩 |
| D-9 | 우체국 10원 단위 처리 | 올림 |
| D-10 | 우체국 차액을 반대로 반영할 기관 | 우체국을 뺀 기관 중 실적회비가 가장 큰 기관 |
| D-11 | 실적 파일에 없는 분담 대상 기관 | 실적 0건으로 보고 균등회비만 부과 |
| D-12 | 같은 기관명이 여러 행일 때 | 같은 기관으로 합산 (대용 담당자 확인 2026-10-17, 공통 미확정) |

추가로 공통에서 정해야 할 것:
- D-13 산출 주기: 대용은 3개월(달력 분기)마다 산출. 회계연도 분기를 쓰는 업무가 있는지.
- D-14 균등회비 분모: 분기 중간 가입·탈퇴 기관을 그 분기 분담 대상에 넣는지 (대용 기본값: 그 분기 실적 데이터에 있는 기관).
- D-15 기관명 동일성: 띄어쓰기만 다른 이름을 같은 기관으로 볼지 (대용 기본값: 같은 기관).

## 10. 엑셀 실적 업로드

- R-10.1 (필수) .xlsx 업로드 → 열 매핑 → 검증 → 미리보기 → "실적 데이터 적용" → 인정 항목 선택 → 실적회비 자동 산출이 한 흐름으로 이어진다. 업로드 즉시 회비를 확정하지 않는다.
- R-10.2 (필수) 열 이름을 읽어 매핑을 자동 추정하고 담당자가 고칠 수 있다. 매핑은 업무별로 저장해 재사용한다.
- R-10.3 (필수) 업로드 정보: 산출 연도, 대상 분기, 실적 시작일·종료일, 적용 업무명.
- R-10.4 (필수) 검증 항목과 오류 위치(행·기관·항목) 표시: 빈 기관명, 미등록 기관명, 중복 기관, 숫자가 아닌 값·음수·소수, 인정 항목 열 누락, 합계 열과 항목 합 불일치, 업로드 기관 수와 분담 대상 기관 수 불일치. 오류가 있으면 적용을 막는다.
- R-10.5 (필수) 합계 열은 검증에만 쓰고 계산에 더하지 않는다.
- R-10.6 (필수) 업로드 후에도 건수·기관 연결을 수정할 수 있고, 수정하면 즉시 재계산한다.
- R-10.7 (필수) **기관명 자동 등록**: 엑셀에만 있는 기관명은 미리보기에서 "신규"로 표시하고, 적용할 때 참가기관으로 자동 등록한다. 담당자가 일일이 입력하지 않는다. 행마다 기존 기관에 연결하거나 제외할 수 있고, 업무별로 자동 등록을 끌 수 있다. 참가기관 화면에서도 엑셀로 기관명만 불러올 수 있다.

## 11. 참가기관

- R-11.1 (필수) 업무별로 참가기관을 등록·수정·추가·제외하고, 분담 대상 기관 수를 자동 집계한다.
- R-11.2 (필수) 기관 추가·제외는 균등회비 분모와 실적 합계에 바로 반영된다.

## 12. 검증

- R-12.1 (필수) 산출할 때마다 다음을 자동 검증한다.
  1. 균등회비 합계 + 실적회비 합계 = T
  2. 전체 기관 회비 합계 = T
  3. 1~4분기 합계 = D
  4. 우체국 보정 전후 합계 유지, 우체국 1원 자리 0
  5. 균등회비 방식 A: 기관별 합계 = 균등회비 총액 / 방식 B: 모든 기관 동일
  6. 비율 합 100%, 음수 회비 없음, 실적 누락 기관, 인정 실적 합계 0
- R-12.2 (필수) 결과는 일치 / 불일치 / 확인 필요로 표시하고, 불일치 때는 기준 총액·실제 총액·차액·원인·보정 대상 기관을 함께 보여 준다.

## 13. 산출 근거 (역추적)

- R-13.1 (필수) 결과 표에서 기관명을 누르면 그 기관의 산출 상세를 보여 준다: 기본 정보(기관·연도·분기·업무), 균등회비 단계, 실적회비 단계(항목별 건수, 인정 실적, 전체 합계, 점유율, 원 단위 처리 전후), 조정 내역(금액·대상·사유, 우체국 처리 포함), 최종 청구금액, 원본 데이터(파일·기준기간), 적용 옵션.
- R-13.2 (필수) 실제 대입한 계산식을 보여 준다. 예: 7,500,000 × (1,200 / 12,000) = 750,000원. 조정이 있으면 "최초 750,000 → 우체국 보정 −3 → 최종 749,997"처럼 이유와 함께 보여 준다.
- R-13.3 (필수) 근거는 계산 엔진이 계산하는 그 자리에서 기록한다. 화면이 별도로 다시 계산해 설명을 만들지 않는다 (설명과 실제 계산이 어긋나지 않게).

## 14. 결과 출력

- R-14.1 (필수) 결과 화면 표: 기관명, 인정 실적, 실적 점유율, 균등회비, 실적회비, 조정금액, 최종 회비. 하단에 기관 수, 균등·실적·전체 합계, 청구 대상 총액, 합계 일치·차액 여부.
- R-14.2 (필수) 결과를 Excel로 내려받는다: 기관별 균등회비·실적회비·조정금액·최종 회비·합계, 적용 옵션과 확인 필요 항목의 확정 여부.

## 15. 화면 구성 (권장)

1 업무·참가기관 · 2 산출 조건 · 3 실적 데이터(엑셀) · 4 금액 보정 · 5 산출 결과 · 6 기관별 산출 근거. 담당자가 계산식을 입력하지 않고 버튼·선택·체크박스·파일 업로드로 쓸 수 있게 한다.
