# 회비 산출 프로그램 설계 (v4, 통합 요구사항)

요구사항 "회비 산출 프로그램 개발 요구사항 (통합본)"을 기준으로 한 화면·데이터·계산 엔진 설계와, 요구사항에 정해지지 않아 **담당자 확인이 필요한 항목**을 정리한다. 구현과 무관한 규칙만 모은 공통 규칙 초안은 [`COMMON_RULES_DRAFT.md`](COMMON_RULES_DRAFT.md).

## 1. 구조

```
src/
  engine/            계산 로직 (화면과 무관, node:test로 검증)
    money.js         BigInt 정수 나눗셈(내림·반올림·올림), 정확한 소수 표시, % ↔ bp
    quarters.js      연간 회비 A·잉여금 B·1분기 기청구 C → 분기별 청구 대상 총액 (3장)
    fee.js           분기 총액 → 균등회비·실적회비·원 단위 조정·우체국 처리·검증 (4~8장)
    perfImport.js    엑셀 열 매핑 추정, 업로드 검증, 미리보기, 실적 적용 (10장)
    period.js        기준월·일자·분기 값 → 날짜 범위
    model.js         업무 데이터 구조, 담당자 확인 항목(DECISIONS), 예시 업무
    pipeline.js      runBusiness(업무) = 12-8 계산 순서 전체 실행
  excel.js           엑셀 읽기·결과/양식 엑셀 쓰기 (계산 없음)
  ui/                화면 1~6
  App.jsx            업무 선택, 탭, 요약 줄, 자동 저장
```

화면은 `runBusiness()`가 돌려준 결과만 보여 준다. 기관별 산출 근거(trace)는 엔진이 계산하는 그 자리에서 기록하므로 화면 설명과 실제 계산이 어긋날 수 없다(12-3). 새 업무별 산출 방식은 `fee.js`에 방식을 추가하고 `settings`에 옵션 하나를 두면 된다.

## 2. 화면

| 번호 | 탭 | 내용 |
|---|---|---|
| 1 | 업무·참가기관 | 업무 추가·복제·삭제, 설정 내보내기/불러오기(JSON), 참가기관 추가(한 건·여러 건·엑셀에서 기관명 불러오기)·이름 수정·분담 대상 제외·삭제·기관 수 |
| 2 | 산출 조건 | 연도·분기, A·B(확정 여부)·C(자동 A÷4 또는 직접 입력), 분기 배분 방식 A/B와 분기별 표·계산식, 분기 원 단위 처리와 차액 반영 분기, 균등·실적 비율(합 100% 확인), 균등회비 방식 A/B, 실적 인정 항목 체크·추가·이름 변경 |

| 4 | 금액 보정 | 균등회비 원 단위 조정(기본금액 처리 방식, ±1원 대상 자동/직접 선택), 실적회비 원 단위 잔액 배정, 우체국 특수 처리(적용 여부·대상·올림/내림·반대 조정 기관·보정 전후 표). 바꾸면 바로 재검증 |
| 5 | 산출 결과 | 기관별 인정 실적·점유율·균등회비·실적회비·조정금액·최종 회비와 합계, 검증 결과(일치/불일치/확인 필요, 기대·실제·차이·원인·대상), 담당자 확인 목록, 결과 엑셀 |
| 6 | 기관별 산출 근거 | 기관명을 누르면 열림. 균등회비 단계, 실적회비 단계와 계산식, 조정 내역과 사유, 최종 금액, 원천 데이터(파일·기준기간), 적용 옵션. 이전/다음 기관 이동 |

## 3. 데이터 구조 (업무 1개)

```js
{
  id, name,
  orgs: [{ id, name, active }],            // active=false면 분담 대상 제외
  items: [{ id, name }],                   // 실적 항목 (사용자 정의 추가 가능)
  recognizedItemIds: ['seizure', ...],     // 실적으로 인정할 항목
  settings: {
    year, quarter,
    annualFee /*A*/, surplus /*B*/, surplusConfirmed, q1Billed /*C, null=A÷4*/,
    quarterMethod: 'A'|'B', quarterRounding, quarterDiffQuarter,
    equalRateBp, perfRateBp,               // 2500 = 25.00%
    equal: { method: 'A'|'B', poolRounding, unitRounding, targetMode, targetOrgIds,
             bMode: 'auto'|'manual', bUnit, bRounding, bAmount },
    perfRemainder: { mode, orgIds },
    postOffice: { enabled, orgId, direction: 'up'|'down', counterpartMode, counterpartOrgId },
    duplicatePolicy: 'sum'|'error',
    autoAddOrgs: true,                     // 실적 엑셀에만 있는 기관명을 참가기관으로 자동 등록
    perfPeriod: { start, end },
  },
  columnMapping: { '엑셀 머리글': 'org'|'total'|'period'|'item:<id>'|'ignore' },
  perf: { [orgId]: { [itemId]: 건수 } },
  perfMeta: { fileName, sheet, start, end, year, quarter, appliedAt, edited },
  confirmed: { [결정 key]: true },         // 담당자가 확인한 기본값
}
```

업무마다 이 묶음을 따로 가지며(12-1), 브라우저에 자동 저장되고 JSON으로 내보내 다시 쓸 수 있다(12-7).

## 4. 계산 순서 (12-8)

1. 연간 회비 A, 전기이월잉여금 B → D = A − B
2. 1분기 기청구 C(고정) → E = D − C
3. 분기 배분 방식으로 2~4분기 금액, 원 단위 처리, 차액은 지정 분기에 더함
4. 산출 분기의 청구 대상 총액 T
5. 균등회비 총액, 실적회비 총액 = T − 균등회비 총액
6. 기관별 균등회비 (방식 A: 기본금액 + 지정 기관 ±1원 / 방식 B: 모두 같은 금액)
7. 기관별 실적회비 = 실적회비 총액 × 인정 실적 ÷ 전체 인정 실적, 원 미만 버림
8. 실적회비 원 단위 잔액 1원씩 배정
9. 우체국 특수 처리 (우체국 실적회비 ±, 지정 기관 실적회비 ∓)
10. 검증

모든 금액은 BigInt 정수로 계산해 부동소수점 오차가 없다(12-4). 각 단계는 한 번만 적용되고, 같은 입력이면 항상 같은 결과다.

## 5. 검증 항목 (8장)

1~4분기 합계 = D · 균등+실적 합계 = 분기 총액 · 전체 기관 합계 = 분기 총액 · 방식 A 균등회비 합계 = 균등회비 총액(방식 B는 모든 기관 동일) · 우체국 보정 전후 합계 유지 · 우체국 1원 자리 0 · 비율 합 100% · 음수 회비 없음 · 실적 데이터 누락 기관.
결과는 일치 / 불일치 / 확인 필요로 표시하고 기대 금액·실제 금액·차이·원인·대상 기관을 함께 보여 준다.

## 6. 엑셀 업로드 검증 (10장)

빈 기관명, 미등록 기관(기본: 적용할 때 새 참가기관으로 자동 등록. 행마다 기존 기관에 연결하거나 연결 안 함으로 바꿀 수 있고, 자동 등록을 끄면 직접 연결해야 함), 같은 기관명 여러 행(합산 또는 오류, 설정), 숫자가 아닌 값·음수·소수(행·기관·항목으로 표시), 인정 항목에 매핑된 열 없음, 합계 열과 항목 합 불일치(합계 열은 검증에만 쓰고 계산에 더하지 않음), 파일에 없는 분담 대상 기관, 실적 기간 밖 행 제외. 오류가 있으면 "실적 데이터 적용"이 비활성화되고, 미리보기 표에서 숫자를 바로 고칠 수 있다.

## 7. 담당자 확인이 필요한 항목

요구사항에 정해지지 않아 **프로그램이 기본값으로 계산하고 "확인 필요"로 표시**하는 항목이다. 화면에서 값을 바꾸거나 "이 값으로 확인"을 누르면 그 업무에서 확정된다. 결과 엑셀의 산출옵션 시트에도 확인 여부가 남는다.

| 항목 | 기본값 | 바꾸는 곳 |
|---|---|---|
| 1분기 기청구 회비 | A ÷ 4 자동 (실제 청구액 직접 입력 가능) | 산출 조건 |
| 분기 금액이 나누어떨어지지 않을 때 | 내림 | 산출 조건 |
| 분기 배분 차액을 반영할 분기 | 차액이 생기면 그때 선택 (선택 전에는 검증 불일치) | 산출 조건 |
| 균등회비 총액(방식 A)의 원 미만 처리 | 반올림 | 산출 조건 |
| 기관별 균등회비 기본금액(방식 A)의 원 미만 처리 | 내림 | 금액 보정 |
| 균등회비 ±1원 대상 기관(방식 A) | 참가기관 목록 순서대로 | 금액 보정 |
| 방식 B 기관별 금액의 단위와 처리 | 1원 단위 내림 (직접 지정 가능) | 산출 조건 |
| 실적회비 원 단위 잔액 배정 | 버린 소수점이 큰 기관부터 1원씩 | 금액 보정 |
| 우체국 10원 단위 처리 | 올림 | 금액 보정 |
| 우체국 차액을 반대로 반영할 기관 | 우체국을 뺀 기관 중 실적회비가 가장 큰 기관 | 금액 보정 |
| 실적 파일에 없는 분담 대상 기관 | 실적 0건으로 보고 균등회비만 부과 | 실적 데이터 |
| 같은 기관명이 여러 행일 때 | 같은 기관으로 합산 (John 확인 2026-10-17) | 실적 데이터 |

그 밖에 요구사항에 없는 부분은 계산을 막고 알린다: 전체 인정 실적 0건이면 실적회비를 배분하지 않고 오류, 우체국 보정으로 반대 기관 실적회비가 음수가 되면 오류, 잉여금 B가 A보다 크면 오류.
