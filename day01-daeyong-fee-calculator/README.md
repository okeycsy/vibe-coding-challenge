## 만든 것

설계 상세와 **담당자 확인이 필요한 항목 목록**은 [docs/DESIGN.md](docs/DESIGN.md)에 있다.

### 계산
1. **분기별 청구 대상 총액**: 당초 연간 회비 A, 전기이월잉여금 B, 1분기 기청구 C로 D = A − B, E = D − C.
   - 방식 A(상·하반기 동일): 2분기 = D/2 − C, 3분기 = 4분기 = D/4
   - 방식 B(잔여 3등분): 2~4분기 = (D − C)/3
   - 1분기 기청구액은 잉여금이 확정되어도 바뀌지 않는다. 예: A 1억, B 1,200만, C 2,500만 → 방식 A 2,500/1,900/2,200/2,200만, 방식 B 2,500/2,100/2,100/2,100만
2. **균등회비 / 실적회비 비율**은 업무마다 입력(합 100% 확인).
3. **균등회비** 방식 A(총액 정확성 우선: 기본금액 + 일부 기관 ±1원) 또는 방식 B(기관별 동일 금액 우선: 차이는 실적회비 총액이 흡수).
4. **실적회비** = 실적회비 총액 × 기관 인정 실적 ÷ 전체 인정 실적. 인정 항목은 체크박스로 고르고 사용자 정의 항목을 추가할 수 있다. 원 미만은 버리고 남은 원은 설정한 방법으로 1원씩 배정.
5. **우체국 특수 처리**: 최종 회비 1원 자리를 0으로 맞추도록 우체국 실적회비를 올리거나 내리고, 같은 금액을 지정 기관 실적회비에서 반대로 조정해 합계를 유지.
6. **검증**: 분기 합계, 균등+실적 합계, 전체 합계, 균등회비 총액, 우체국 보정 전후, 비율, 음수, 실적 누락을 일치 / 불일치 / 확인 필요로 표시.

모든 금액은 BigInt 정수로 계산해 부동소수점 오차가 없다.

### 화면 (탭 5개 + 기관별 상세)
1. 업무·참가기관: 업무 추가·복제·삭제, 설정 내보내기/불러오기, 기관 추가·수정·제외·삭제, 엑셀에서 기관명 불러오기
2. 산출 조건: 연도·분기, A·B·C, 분기 배분 방식, 비율, 균등회비 방식, 실적 인정 항목
3. 실적 데이터: 엑셀 업로드 → 업로드 정보(기준기간 시작·종료일) → 열 매핑(자동 추정·저장) → 검증 → 미리보기·수정 → 실적 데이터 적용
4. 금액 보정: 균등회비 ±1원 대상, 실적회비 잔액 배정, 우체국 처리. 바꾸면 바로 재검증
5. 산출 결과: 기관별 표·합계·검증·확인 필요 목록·결과 엑셀
6. 기관명을 누르면 산출 근거(단계별 계산식, 조정 사유, 원천 데이터, 적용 옵션)

처음 열면 가상 기관으로 만든 예시 업무 2개(예금압류 관련정보 중계업무, 오픈API 중계업무)가 들어 있다. 실제 기관·건수가 아니다.

### 실적 엑셀 형식
- 제목 행이 있어도 머리글 행을 자동으로 찾는다. 머리글 이름으로 기관명·실적 항목·합계·기간 열을 추정하고, 담당자가 고친 매핑은 업무에 저장된다.
- 등록되지 않은 기관명은 "실적 데이터 적용" 때 참가기관으로 자동 등록된다(미리보기에 "신규" 표시, 행마다 기존 기관 연결·연결 안 함 선택 가능, 체크박스로 끌 수 있음). 띄어쓰기만 다른 이름은 같은 기관으로 본다.
- 합계 열은 항목 합과 비교하는 데만 쓰고 계산에 더하지 않는다.
- 기간 열(기준월·일자·분기)이 있으면 업로드 정보의 기준기간 안의 행만 쓴다.
- 화면의 "업로드 양식 내려받기"로 현재 업무의 기관·항목 양식을 받을 수 있다.

### 결과 엑셀
`회비산출_<업무명>_<연도>년<분기>분기.xlsx`: 회비산출결과, 분기배분, 검증, 산출근거(기관별 단계), 산출옵션(확인 필요 여부 포함), 실적데이터 시트.

### 실행 방법
```bash
npm install
npm run dev      # 개발 서버 http://localhost:5173
npm test         # 계산 엔진 테스트 (node:test, src/engine/engine.test.js)
npm run build    # dist/ + release/fee-calculator.html(단일 파일 프로그램) 생성
```
브라우저 안에서만 계산하며 업로드한 파일은 서버로 보내지 않는다. 설정과 데이터는 그 브라우저에 자동 저장된다.

### 구성
- `src/engine/` 계산 로직 (화면과 분리): `money.js`, `quarters.js`, `fee.js`, `perfImport.js`, `period.js`, `model.js`, `pipeline.js`
- `src/excel.js` 엑셀 읽기·쓰기 (계산 없음)
- `src/ui/` 화면 1~6, `src/App.jsx` 탭·요약·저장
- `scripts/build-single.js` 빌드 결과를 HTML 파일 하나로 묶기

## 사용한 프롬프트 / 과정
- 1차: 회비 총액 + 건수 엑셀 → 25% 균등 / 75% 건수 비율 안분 → 결과 엑셀
- 2차: 프로그램 형태 화면, 단일 HTML 파일
- 3차: 3년치 파일을 분기별로 산출, 같은 기관명 합산
- 4차(v4): 통합 요구사항으로 재구성. 업무별 설정, 분기 배분 방식, 균등회비 방식 A/B, 실적 인정 항목, 우체국 처리, 열 매핑·검증·미리보기, 기관별 산출 근거. 요구사항에 없는 원 단위 규칙은 기본값으로 두고 "확인 필요"로 표시
