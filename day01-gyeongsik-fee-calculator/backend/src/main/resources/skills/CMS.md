# CMS 회비 산정 기준 (CMS)

- 업무명: CMS
- 산정 유형: 기본료 + 건당 단가
- 표시 단위: 원/건

## 1. 비즈니스 규칙 요약

- 자동이체 출금 의뢰 처리 건을 실적으로 인정 (반송·불능 건도 처리 건수에 포함)
- 기본료: 분기 90만원 (해당 기간 인정 실적이 1건 이상인 기관만 부과, 분기가 아니면 일수 비례)
- 건당 단가 8원을 기본료에 더해 부과

## 2. AI 예외 차감 지침

- 결제원 시스템 장애로 출금 의뢰가 처리되지 않고 재의뢰된 건은 차감한다.
- 반송·불능 건은 처리 건수에 포함하므로 차감하지 않는다.
- 차감으로 인정 실적이 0건이 되면 기본료도 부과되지 않는다는 점을 확인한다.

## 3. 정산 수식

변수: `#finalCount` 최종 인정 건수, `#periodScale` 기간 환산 비율(분기 = 1).

```formula
(#finalCount > 0 ? 900000 * #periodScale : 0) + #finalCount * 8
```
