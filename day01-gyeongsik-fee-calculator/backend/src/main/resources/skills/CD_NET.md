# CD공동망 회비 산정 기준 (CD_NET)

- 업무명: CD공동망
- 산정 유형: 균등 분담 + 실적 비례 분담
- 표시 단위: %

## 1. 비즈니스 규칙 요약

- 분기 공동망 운영비 총액 3억원을 참가기관이 분담 (분기가 아니면 일수 비례)
- 총액의 30%는 참가기관 수로 균등 분담
- 나머지 70%는 기관별 타행 CD/ATM 거래 인정 건수 비율로 분담
- 망 장애로 인한 재처리 건은 차감 대상

## 2. AI 예외 차감 지침

- 공동망 장애로 같은 거래를 재처리한 건은 재처리 건수만큼 차감한다.
- 기관 자체 ATM 장애로 고객이 다시 시도한 건은 정상 거래이므로 차감하지 않는다.
- 차감은 70% 실적 비례 부분에만 영향을 주고, 30% 균등 분담액은 그대로다.

## 3. 정산 수식

변수: `#finalCount` 기관 인정 건수, `#totalCount` 전체 인정 건수 합계, `#institutionCount` 참가기관 수, `#periodScale` 기간 환산 비율.

```formula
300000000.0 * #periodScale * (0.3 / #institutionCount + (#totalCount == 0 ? 0 : 0.7 * #finalCount / #totalCount))
```
