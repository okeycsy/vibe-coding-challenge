# 금융거래정보(금거정) 회비 산정 기준 (FIN_INFO)

- 업무명: 금융거래정보(금거정)
- 산정 유형: 총액 대비 비율 분담
- 표시 단위: %

## 1. 비즈니스 규칙 요약

- 분기 운영비 총액 1억 2,000만원을 참가기관이 분담
- 분담률 = 기관별 최종 인정 건수 ÷ 전체 기관 최종 인정 건수 합계
- 분기가 아닌 기간은 총액을 일수 ÷ 91일 비율로 환산
- 시험·테스트 전문은 실적에서 제외

## 2. AI 예외 차감 지침

- 시험·테스트 전문(테스트 계좌, 개발계 송신 등)으로 확인된 건수는 전액 차감한다.
- 조회 전문 타임아웃으로 같은 요청을 다시 보낸 재요청 건은 차감한다.
- 차감 후 분담률이 바뀌어 다른 기관 회비가 함께 달라진다는 점을 결과에 알린다.

## 3. 정산 수식

변수: `#finalCount` 기관 최종 인정 건수, `#totalCount` 전체 기관 인정 건수 합계, `#periodScale` 기간 환산 비율(분기 = 1).
원 단위는 엔진이 원 미만 버림 후 최대잔여법으로 맞춰 합계 = 총액이 된다.

```formula
#totalCount == 0 ? 0 : 120000000.0 * #periodScale * #finalCount / #totalCount
```
