# 오픈뱅킹 회비 산정 기준 (OPEN_BANKING)

- 업무명: 오픈뱅킹
- 산정 유형: 구간별 차등 단가
- 표시 단위: 원/건

## 1. 비즈니스 규칙 요약

- 이용기관 API 호출 중 출금이체·입금이체 성공 건을 실적으로 인정 (조회성 API는 산정 제외)
- 구간별 차등 단가(누진 감액): 100만 건까지 건당 20원, 100만 건 초과 ~ 300만 건 15원, 300만 건 초과분 10원
- 구간은 산출 기간 전체의 최종 인정 건수 기준으로 나눔
- 장애·중복 전송 건은 증빙 확인 후 실적에서 차감

## 2. AI 예외 차감 지침

- 시스템 장애로 이용기관이 같은 거래를 다시 보낸 경우, 재전송된 건수만큼 차감한다.
- 같은 거래고유번호로 2회 이상 들어온 중복 전송 건은 1건만 남기고 차감한다.
- 이용기관 쪽 단순 오류(잘못된 계좌번호 등)로 실패한 건은 애초에 성공 건이 아니므로 차감 대상이 아니다.
- 기관명과 건수가 문장에 없으면 차감하지 않고 담당자에게 확인을 요청한다.

## 3. 정산 수식

변수: `#finalCount` 최종 인정 건수. 1구간 최대 금액 2,000만원(100만 × 20원), 2구간까지 최대 5,000만원(+200만 × 15원).

```formula
#finalCount <= 1000000
  ? #finalCount * 20
  : (#finalCount <= 3000000
      ? 20000000 + (#finalCount - 1000000) * 15
      : 50000000 + (#finalCount - 3000000) * 10)
```
