# 타행환 회비 산정 기준 (INTERBANK)

- 업무명: 타행환
- 산정 유형: 건당 단가 + 최저·최고 한도
- 표시 단위: 원/건

## 1. 비즈니스 규칙 요약

- 타행 송금 의뢰 성공 건을 실적으로 인정 (정정·취소 전문은 산정 제외)
- 건당 단가 12원 적용
- 최저 회비 50만원, 최고 회비 1억원 (한도 안에서만 단가 적용)

## 2. AI 예외 차감 지침

- 정정·취소 전문이 성공 건으로 잘못 집계된 경우 그 건수만큼 차감한다.
- 수취은행 장애로 반환된 송금 건은 차감한다.
- 차감 후에도 최저 회비 50만원은 부과되므로, 소규모 기관의 차감 요청은 금액 영향이 없을 수 있음을 알린다.

## 3. 정산 수식

변수: `#finalCount` 최종 인정 건수.

```formula
#finalCount * 12 < 500000
  ? 500000
  : (#finalCount * 12 > 100000000 ? 100000000 : #finalCount * 12)
```

## 4. 최종 정산 특이사항

- 참가기관 중 1개 기관(첫 번째 기관 또는 지정 기관)은 산출된 회비 총액을 10원 단위로 절상한다.
- 절상으로 인해 발생한 차이분(초과액)은 최종 인정 실적(#finalCount)이 큰 기관 순서대로 1원씩 절삭하여 분기 총액을 맞춘다.
